- Harness store writes now validate entry shape before persisting: `rlm.harness` create/update/upsert calls reject non-string or empty `title`/`content`, malformed ids/paths, non-dict `reference`/`arguments`/`metadata`, and skill entries without a valid Python reference, with an error naming the entry and the field; refinement events reject non-string triggers and invalid `changes`.
- The harness digest and refine overview now skip malformed persisted entries and refinement events with a `harness: skipped malformed entry <id> (...)` diagnostic line instead of crashing session creation, so a single corrupt store entry can no longer brick every session and child spawn.
